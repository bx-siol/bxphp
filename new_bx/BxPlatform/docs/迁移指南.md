# PHP 到 .NET 迁移指南

## 📋 概述

本文档指导如何将现有 PHP 项目逐步迁移到 .NET 8.0 分布式架构。

---

## 🎯 迁移目标

### 架构升级
- ✅ 单体应用 → 分布式架构
- ✅ 同步执行 → 异步编程
- ✅ MySQL单库 → PostgreSQL分库分表
- ✅ 直接数据库操作 → 仓储模式
- ✅ 过程式编程 → DDD领域驱动

### 性能提升
- ✅ 支持并发: 100 → 100,000
- ✅ QPS: 1,000 → 50,000+
- ✅ 响应时间: 100ms → 50ms

### 阶段2: 数据迁移(3-5天)

#### 2.1 迁移策略选择

**方案A: 停机迁移(适合小型系统)**
1. 停止PHP应用
2. 全量数据导出
3. 导入到PostgreSQL
4. 启动.NET应用

**方案B: 双写方案(推荐,零停机)**
1. .NET应用上线,读取MySQL
2. 写操作同时写MySQL和PostgreSQL
3. 历史数据后台迁移
4. 验证数据一致性
5. 切换读取到PostgreSQL
6. 停止MySQL写入

**方案C: 灰度迁移(最安全)**
1. 按用户ID分批迁移
2. 10% → 30% → 50% → 100%
3. 每个阶段观察系统稳定性

#### 2.2 数据迁移脚本示例

```csharp
// 用户数据迁移
public async Task MigrateUsersAsync()
{
    // 从MySQL读取
    var mysqlUsers = await _mysqlRepo.GetAllUsersAsync();
    
    foreach (var user in mysqlUsers)
    {
        // 转换为.NET实体
        var sysUser = new SysUser(
            user.Account,
            user.Password,
            user.Nickname,
            user.ParentId);
        
        // 保存到PostgreSQL(自动分表)
        await _pgUserRepo.AddAsync(sysUser);
    }
}
```

### 阶段3: 代码迁移(10-15天)

#### 3.1 PHP vs .NET 对照表

| 功能 | PHP | .NET |
|-----|-----|------|
| 数据库操作 | `Db::table('user')->find(1)` | `await _repository.GetByIdAsync(1)` |
| 加密 | `getPassword($pwd, true)` | `EncryptionHelper.GetPassword(pwd, true)` |
| 缓存 | `Redis::get($key)` | `await _cache.GetAsync<T>(key)` |
| 分表路由 | `getUserTable($uid)` | `ShardingRouter.GetUserTable(uid)` |
| 事务 | `Db::startTrans()` | `await _uow.BeginTransactionAsync()` |
| 返回JSON | `ReturnToJson(1, $data)` | `ApiResult.Success(data)` |

#### 3.2 典型控制器迁移示例

**PHP代码:**
```php
<?php
class UserController extends BaseController
{
    public function _user()
    {
        $uid = input('id');
        $user = Db::table('sys_user')->where("id={$uid}")->find();
        return ReturnToJson(1, 'ok', $user);
    }
    
    public function _user_pay()
    {
        $uid = input('id');
        $money = input('money');
        
        Db::startTrans();
        try {
            $user = Db::table('sys_user')->lock(true)->where("id={$uid}")->find();
            Db::table('sys_user')->where("id={$uid}")->update([
                'balance' => $user['balance'] + $money
            ]);
            Db::commit();
            return ReturnToJson(1, '充值成功');
        } catch (Exception $e) {
            Db::rollback();
            return ReturnToJson(-1, $e->getMessage());
        }
    }
}
```

**.NET代码:**
```csharp
[ApiController]
[Route("api/v1/[controller]")]
public class UsersController : ControllerBase
{
    private readonly IUserService _userService;
    
    public UsersController(IUserService userService)
    {
        _userService = userService;
    }
    
    // 获取用户信息
    [HttpGet("{id}")]
    public async Task<IActionResult> GetUser(int id)
    {
        try
        {
            var user = await _userService.GetUserByIdAsync(id);
            return Ok(ApiResult.Success(user));
        }
        catch (Exception ex)
        {
            return Ok(ApiResult.Error(ex.Message));
        }
    }
    
    // 充值(带分布式锁)
    [HttpPost("{id}/recharge")]
    public async Task<IActionResult> Recharge(int id, [FromBody] RechargeRequest request)
    {
        try
        {
            var result = await _userService.RechargeAsync(id, request.Amount, request.Remark);
            return Ok(result 
                ? ApiResult.Success("充值成功") 
                : ApiResult.Error("充值失败"));
        }
        catch (Exception ex)
        {
            return Ok(ApiResult.Error(ex.Message));
        }
    }
}

// 服务层实现(带事务和分布式锁)
public class UserService : IUserService
{
    public async Task<bool> RechargeAsync(int userId, decimal amount, string remark)
    {
        var lockKey = $"user:balance:{userId}";
        
        return await _distributedLock.ExecuteWithLockAsync(lockKey, async () =>
        {
            using (var uow = _unitOfWork)
            {
                await uow.BeginTransactionAsync();
                try
                {
                    var user = await _userRepository.GetByIdAsync(userId);
                    user.Recharge(amount);
                    await _userRepository.UpdateAsync(user);
                    
                    await uow.CommitAsync();
                    await _cacheService.RemoveAsync($"user:{userId}");
                    
                    return true;
                }
                catch
                {
                    await uow.RollbackAsync();
                    throw;
                }
            }
        }, TimeSpan.FromSeconds(10));
    }
}
```

## ⚠️ 注意事项

### 1. 密码加密一致性

确保PHP和.NET使用相同的加密算法:

**PHP:**
```php
function getPassword($password, $isOriginal = false) {
    $processedPassword = $isOriginal ? md5($password) : $password;
    return sha1($processedPassword . SYS_KEY . '_kwioxklalis');
}
```

**.NET:**
```csharp
public static string GetPassword(string password, bool isOriginal = false)
{
    string processedPassword = isOriginal ? Md5Encrypt(password) : password;
    return Sha1Encrypt(processedPassword + SYS_KEY + "_kwioxklalis");
}
```

### 2. 时间戳处理

PHP和.NET都使用Unix时间戳(秒):
```csharp
int timestamp = (int)DateTimeOffset.UtcNow.ToUnixTimeSeconds();
```

### 3. 数据库字段映射

使用SqlSugar特性映射:
```csharp
[SugarColumn(ColumnName = "fz_balance", DecimalDigits = 2)]
public decimal FrozenBalance { get; private set; }
```

### 4. 事务隔离级别

PostgreSQL默认是 `READ COMMITTED`,与MySQL一致。
