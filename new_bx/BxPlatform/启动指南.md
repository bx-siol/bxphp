# BxPlatform 启动指南

## 使用 Visual Studio 打开项目

### 方法一：直接打开解决方案文件

1. 双击 `BxPlatform.sln` 文件，Visual Studio 会自动打开
2. 或者在 Visual Studio 中选择 `文件` -> `打开` -> `项目/解决方案`，然后选择 `BxPlatform.sln`

### 方法二：通过文件夹打开

1. 在 Visual Studio 中选择 `文件` -> `打开` -> `文件夹`
2. 选择 `BxPlatform` 文件夹
3. Visual Studio 会自动识别解决方案文件

## 项目结构

解决方案包含以下项目：

```
BxPlatform.sln
├── src
│   ├── 1.Core                          # 核心层
│   │   ├── BxPlatform.Domain           # 领域模型（实体、接口）
│   │   └── BxPlatform.Application      # 应用服务层
│   ├── 2.Infrastructure                # 基础设施层
│   │   ├── BxPlatform.Common           # 公共类库
│   │   └── BxPlatform.Infrastructure   # 基础设施实现（仓储、缓存等）
│   └── 3.Presentation                  # 表示层
│       ├── BxPlatform.Api              # 用户端 API
│       └── BxPlatform.AdminApi         # 管理端 API
```

## 设置启动项目

### 启动管理端 API

1. 在解决方案资源管理器中，右键点击 `BxPlatform.AdminApi` 项目
2. 选择 `设为启动项目`
3. 按 `F5` 或点击工具栏的 `启动` 按钮
4. 浏览器会自动打开 Swagger 文档页面：http://localhost:5100

### 启动用户端 API

1. 在解决方案资源管理器中，右键点击 `BxPlatform.Api` 项目
2. 选择 `设为启动项目`
3. 按 `F5` 或点击工具栏的 `启动` 按钮
4. 浏览器会自动打开 Swagger 文档页面：http://localhost:5000

### 同时启动多个项目

1. 右键点击解决方案根节点
2. 选择 `属性` 或 `配置启动项目`
3. 选择 `多个启动项目`
4. 将 `BxPlatform.Api` 和 `BxPlatform.AdminApi` 的操作设为 `启动`
5. 点击 `确定`
6. 按 `F5` 启动，两个 API 会同时运行

## 编译项目

### 编译整个解决方案

- 快捷键：`Ctrl + Shift + B`
- 或者菜单：`生成` -> `生成解决方案`

### 编译单个项目

1. 在解决方案资源管理器中右键点击项目
2. 选择 `生成`

### 清理项目

- 菜单：`生成` -> `清理解决方案`

## 还原 NuGet 包

第一次打开项目时，Visual Studio 会自动还原 NuGet 包。如果没有自动还原：

1. 右键点击解决方案
2. 选择 `还原 NuGet 程序包`

或者使用命令行：

```bash
dotnet restore
```

## 运行项目

### 在 Visual Studio 中运行

1. 设置启动项目（见上文）
2. 按 `F5`（调试模式）或 `Ctrl + F5`（非调试模式）
3. 浏览器会自动打开 Swagger 文档页面

### 使用命令行运行

#### 运行管理端 API

```bash
cd src/3.Presentation/BxPlatform.AdminApi
dotnet run
```

访问：http://localhost:5100

#### 运行用户端 API

```bash
cd src/3.Presentation/BxPlatform.Api
dotnet run
```

访问：http://localhost:5000

## 配置数据库

在运行项目之前，需要配置数据库连接字符串：

### BxPlatform.AdminApi

编辑 `src/3.Presentation/BxPlatform.AdminApi/appsettings.json`：

```json
{
  "ConnectionStrings": {
    "BxCore": "Host=localhost;Port=5432;Database=bx_core;Username=postgres;Password=admin8",
    "BxFinance": "Host=localhost;Port=5432;Database=bx_finance;Username=postgres;Password=admin8",
    "BxTrade": "Host=localhost;Port=5432;Database=bx_trade;Username=postgres;Password=admin8",
    "BxMarketing": "Host=localhost;Port=5432;Database=bx_marketing;Username=postgres;Password=admin8",
    "BxLog": "Host=localhost;Port=5432;Database=bx_log;Username=postgres;Password=admin8",
    "Redis": "localhost:6379,password=123456,defaultDatabase=0"
  }
}
```

### BxPlatform.Api

编辑 `src/3.Presentation/BxPlatform.Api/appsettings.json`（配置相同）

## 调试技巧

### 设置断点

1. 在代码编辑器中，点击代码行号左侧的边缘，或按 `F9`
2. 按 `F5` 以调试模式启动项目
3. 当代码执行到断点时会暂停

### 调试快捷键

- `F5`：继续执行
- `F10`：单步跳过
- `F11`：单步进入
- `Shift + F11`：单步跳出
- `Shift + F5`：停止调试

### 查看变量值

- 鼠标悬停在变量上查看值
- 使用 `监视` 窗口添加要监视的变量
- 使用 `即时窗口`（`Ctrl + Alt + I`）执行代码

## 发布项目

### 发布到文件夹

1. 右键点击要发布的项目（如 `BxPlatform.AdminApi`）
2. 选择 `发布`
3. 选择 `文件夹` 作为目标
4. 选择发布路径
5. 点击 `发布` 按钮

### 使用命令行发布

```bash
# 发布管理端 API
cd src/3.Presentation/BxPlatform.AdminApi
dotnet publish -c Release -o ./publish

# 发布用户端 API
cd src/3.Presentation/BxPlatform.Api
dotnet publish -c Release -o ./publish
```

## 常见问题

### 1. 项目无法编译

- 确保已安装 .NET 10.0 SDK
- 检查 NuGet 包是否已还原
- 清理解决方案后重新生成

### 2. 端口被占用

修改项目的 `Properties/launchSettings.json` 文件，更改端口号。

### 3. 数据库连接失败

- 检查 PostgreSQL 服务是否运行
- 检查连接字符串是否正确
- 检查数据库是否已创建

### 4. Redis 连接失败

- 检查 Redis 服务是否运行
- 检查 Redis 连接字符串和密码是否正确
