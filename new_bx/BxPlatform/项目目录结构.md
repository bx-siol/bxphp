## 🚀 快速开始

1. 执行创建脚本:
```powershell
.\创建项目脚本.ps1
```

2. 复制已创建的文件到对应目录

3. 还原NuGet包:
```bash
dotnet restore
```

4. 编译项目:
```bash
dotnet build
```

5. 运行API:
```bash
cd src\3.Presentation\BxPlatform.Api
dotnet run
```

6. 访问Swagger: http://localhost:5000
