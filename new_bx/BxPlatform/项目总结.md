## 🎯 核心特性

### 1. DDD分层架构
- **领域层**: 核心业务逻辑,不依赖外部框架
- **应用层**: 用例编排,事务管理
- **基础设施层**: 技术实现(数据库、缓存、锁)
- **表现层**: API接口,轻量级

### 2. 分库分表支持
```csharp
// 自动路由到对应分表
var tableName = ShardingRouter.GetUserTable(userId); // sys_user_3
var user = await _userRepository.GetByIdAsync(userId);
```

支持的分表:
- ✅ 用户表: 16张分表 (`sys_user_0` ~ `sys_user_15`)
- ✅ 充值记录: 32张分表 (`fin_paylog_0` ~ `fin_paylog_31`)
- ✅ 订单表: 32张分表 (`pro_order_0` ~ `pro_order_31`)
- ✅ 钱包表: 16张分表 (`wallet_list_0` ~ `wallet_list_15`)
- ✅ 其他7种分表规则

### 3. 三级缓存
```
请求 → 本地内存缓存 → Redis缓存 → PostgreSQL数据库
```

```csharp
// 自动处理缓存穿透
var user = await _cacheService.GetOrSetAsync($"user:{userId}", async () =>
{
    return await _userRepository.GetByIdAsync(userId);
}, TimeSpan.FromMinutes(30));
```

### 4. 分布式锁
```csharp
// 充值时防止并发问题
var lockKey = $"user:balance:{userId}";
await _distributedLock.ExecuteWithLockAsync(lockKey, async () =>
{
    var user = await _userRepository.GetByIdAsync(userId);
    user.Recharge(amount);
    await _userRepository.UpdateAsync(user);
}, TimeSpan.FromSeconds(10));
```

### 5. 工作单元(事务)
```csharp
using (var uow = _unitOfWork)
{
    await uow.BeginTransactionAsync();
    try
    {
        await _userRepository.UpdateAsync(user);
        await _walletRepository.UpdateAsync(wallet);
        await uow.CommitAsync();
    }
    catch
    {
        await uow.RollbackAsync();
        throw;
    }
}
```

## 💡 核心亮点

### 1. 业务逻辑封装在领域实体
```csharp
public class SysUser : Entity, IAggregateRoot
{
    public void Recharge(decimal amount)
    {
        if (amount <= 0)
            throw new ArgumentException("充值金额必须大于0");
        Balance += amount;
        UpdateTimestamp();
    }
}
```

### 2. 自动分表路由
```csharp
// 根据用户ID自动路由到对应分表
public override async Task<SysUser?> GetByIdAsync(int id)
{
    var tableName = ShardingRouter.GetUserTable(id);
    return await _db.Queryable<SysUser>()
        .AS(tableName)
        .Where(u => u.Id == id)
        .FirstAsync();
}
```

### 3. 缓存穿透保护
```csharp
// 自动处理缓存未命中情况
public async Task<T> GetOrSetAsync<T>(string key, Func<Task<T>> factory, TimeSpan? expiry = null)
{
    var cached = await GetAsync<T>(key);
    if (cached != null) return cached;
    
    var value = await factory();
    if (value != null)
    {
        await SetAsync(key, value, expiry ?? TimeSpan.FromMinutes(30));
    }
    return value;
}
```

### 4. 分布式锁保护并发操作
```csharp
// 自动获取锁、执行操作、释放锁
public async Task<T> ExecuteWithLockAsync<T>(string key, Func<Task<T>> action, TimeSpan expiry)
{
    var acquired = await AcquireLockAsync(key, expiry);
    if (!acquired) throw new TimeoutException($"无法获取锁: {key}");
    
    try
    {
        return await action();
    }
    finally
    {
        await ReleaseLockAsync(key);
    }
}
```
