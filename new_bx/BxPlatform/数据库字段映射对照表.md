## 字段命名规则

### 数据库 → C#

1. **下划线转驼峰**: `first_pay_day` → `FirstPayDay`
2. **缩写展开**: `pid` → `ParentId`, `gid` → `GroupId`, `uid` → `Uid`
3. **特殊前缀处理**:
   - `is_` → `Is` (如: `is_first` → `IsFirst`)
   - `ori_` → `Original` (如: `ori_balance` → `OriginalBalance`)
   - `fz_` → `Frozen` (如: `fz_balance` → `FrozenBalance`)

4. **时间字段统一**: `create_time` → `CreateTime`, `reg_time` → `RegisterTime`

5. **金额字段**: 保持 `Money`, `Price` 等简洁命名

## 注意事项

1. **时间格式**:
   - Unix时间戳: 使用 `int` 类型存储秒级时间戳
   - Ymd日期: 使用 `int` 类型存储,格式如 `20260111`
   - PostgreSQL时间戳: 使用 `DateTime?` 类型

2. **可空性**:
   - 数据库中 `NOT NULL` 的字段对应C#中的非空类型
   - 数据库中可空字段对应C#中的 `?` 可空类型

3. **唯一性**:
   - `account`, `icode`, `osn`, `token` 等字段在数据库中有唯一约束
   - 在C#实体中通过 `[SugarColumn]` 特性标注

4. **外键关系**:
   - 数据库层面有外键约束的字段(如 `uid` 引用 `sys_user.id`)
   - 在C#实体中暂未使用导航属性,保持扁平化设计
