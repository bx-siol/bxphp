## 四、并发和性能测试

### 4.1 并发充值测试

**目标：** 验证事务和行锁的正确性

**准备工作：**
```sql
-- 设置测试用户余额为1000
UPDATE sys_user SET balance = 1000.00 WHERE id = 100001;
```

**测试脚本：**（使用Python或其他工具）
```python
import requests
import threading

def charge_money():
    url = "http://localhost:5000/api/?m=Admin&c=User&a=user_pay"
    data = {
        "id": 100001,
        "money": 10,
        "ptype": 1
    }
    response = requests.post(url, data=data)
    print(response.json())

# 创建10个线程并发充值
threads = []
for i in range(10):
    t = threading.Thread(target=charge_money)
    threads.append(t)
    t.start()

for t in threads:
    t.join()
```

**验证：**
```sql
-- 查询最终余额
SELECT balance FROM sys_user WHERE id = 100001;
-- 应该是：1100.00 (初始1000 + 10次充值 * 10元)
```

**验证点：**
- ✅ 最终余额正确
- ✅ 没有丢失充值记录
- ✅ 事务隔离级别正确

## 七、常见问题排查

### 问题1：服务启动失败

**现象：** `dotnet run` 报错

**排查步骤：**
1. 检查.NET SDK版本：`dotnet --version`（应该是8.0或更高）
2. 检查端口占用：`netstat -ano | findstr 5000`
3. 检查数据库连接：确认PostgreSQL服务已启动
4. 查看详细错误日志

### 问题2：数据库连接失败

**现象：** 请求接口返回数据库连接错误

**排查步骤：**
1. 检查PostgreSQL服务状态
2. 验证连接字符串（appsettings.json）
3. 测试数据库连接：`psql -U postgres -h localhost -p 5432 -d bx_core`
4. 检查防火墙设置

### 问题3：路由不匹配

**现象：** 404 Not Found

**排查步骤：**
1. 确认URL格式：`/api/?m=Admin&c=User&a=user`
2. 检查中间件是否正确注册（Program.cs）
3. 查看控制器路由配置
4. 检查请求方法（GET/POST）是否正确

### 问题4：返回格式不一致

**现象：** 返回的JSON格式与PHP不同

**排查步骤：**
1. 检查ApiResult类定义
2. 确认JSON序列化配置（Program.cs）
3. 对比PHP和Furion的返回结果
4. 检查字段命名策略（应该保持原样，不使用驼峰）
