# PHP用户控制器 → Furion控制器复刻 - 项目交付文档

## 📋 项目概述

本项目完成了PHP用户控制器到.NET 10 + Furion框架的完整复刻，严格遵循「先复刻、后优化」的原则，确保与原有PHP系统100%兼容。

**项目名称：** BX系统用户控制器重构（第1阶段）  
**技术栈：** .NET 10 + Furion 4.8+ + SqlSugar Core 5.1+ + PostgreSQL  
**交付日期：** 2024年1月  
**项目状态：** ✅ 已完成第一阶段交付

---

## 🎯 核心目标

### 已完成目标

1. ✅ **接口完全兼容**：所有PHP接口功能100%复刻，URL、参数、返回格式完全一致
2. ✅ **业务逻辑复刻**：密码加密、参数校验、错误处理与PHP完全一致
3. ✅ **数据库操作迁移**：使用SqlSugar实现与ThinkORM等效的操作
4. ✅ **路由兼容**：支持PHP风格路由格式（/api/?m=Admin&c=User&a=方法名）
5. ✅ **分库支持**：配置5个PostgreSQL分库（bx_core/bx_trade/bx_finance/bx_marketing/bx_log）
6. ✅ **预留扩展点**：为后续优化（服务层、仓储层、队列）预留接口

## 🔧 技术实现详情

### 1. 核心文件说明

#### 1.1 UserController.cs（880行）

**位置：** `new_bx/new_bx.Api/Controllers/Admin/UserController.cs`

**功能：** 完整复刻PHP用户控制器的所有接口

**实现的接口：**
1. `User()` - 用户列表查询（支持多种筛选条件、分页）
2. `UserUpdate()` - 用户更新/新增（参数校验、密码加密）
3. `UserDelete()` - 用户删除（软删除、超管保护）
4. `UserKick()` - 踢用户下线
5. `UserPay()` - 用户充值/扣款（事务处理、行锁）
6. `UpdateUserfirstPayDay()` - 切换首充日期
7. `DisableStatus()` - 批量状态操作
8. `TransferAct()` - 转移下级（事务处理）

**代码特点：**
- 异步方法（async/await）提升性能
- 完整的异常处理
- 详细的中文注释
- 预留扩展点标注

#### 1.2 SysUserEntity.cs（360行）

**位置：** `new_bx/new_bx.Common/Entities/SysUserEntity.cs`

**功能：** 系统用户实体类，严格按照PostgreSQL bx_core.sys_user表结构定义

**字段数量：** 51个字段，与数据库完全对齐

**关键字段：**
- `id` - 用户ID（主键）
- `account` - 账号（唯一）
- `password` - 密码（SHA1加密）
- `balance` - 可用余额
- `fz_balance` - 冻结余额
- `status` - 状态（1=禁用，2=正常，99=已删除）
- `pidg1`, `pidg2` - 代理层级关系
- `teamcount` - 团队人数

#### 1.3 EncryptHelper.cs（88行）

**位置：** `new_bx/new_bx.Common/Helpers/EncryptHelper.cs`

**功能：** 加密工具类，与PHP的getPassword()函数完全一致

**加密算法：**
```
最终密码 = SHA1(MD5(原始密码) + SYS_KEY + "_kwioxklalis")
```

**关键常量：**
```csharp
private const string SYS_KEY = "asfasvcv4856e13asd35a3v1a5dv485adcxx";
```

**方法：**
- `GetPassword(password, isOriginal)` - 获取加密密码
- `Md5Encrypt(input)` - MD5加密（小写32位）
- `Sha1Encrypt(input)` - SHA1加密（小写40位）

#### 1.4 ApiResult.cs（119行）

**位置：** `new_bx/new_bx.Common/Models/ApiResult.cs`

**功能：** 通用API返回结果类，与PHP的ReturnToJson()格式完全一致

**返回格式：**
```json
{
  "code": 1,
  "msg": "操作成功",
  "data": { ... }
}
```

**错误码规范：**
- `code = 1` - 操作成功
- `code = 200` - HTTP成功状态
- `code = -1` - 参数错误/业务错误
- `code = -2` - 密码错误
- `code = -99` - 系统错误

#### 1.5 PhpStyleRouteMiddleware.cs（82行）

**位置：** `new_bx/new_bx.Api/Middleware/PhpStyleRouteMiddleware.cs`

**功能：** PHP风格路由中间件，实现路由兼容

**路由转换：**
```
输入：/api/?m=Admin&c=User&a=user_update
转换：/api/User/user_update（内部路由）
```

**特性：**
- 自动解析m（模块）、c（控制器）、a（方法）参数
- 保留其他查询参数
- 支持GET和POST请求

#### 1.6 Program.cs（95行）

**位置：** `new_bx/new_bx.Api/Program.cs`

**功能：** 应用启动配置

**关键配置：**

   - bx_trade - 交易库
   - bx_finance - 财务库
   - bx_marketing - 营销库

## 📝 接口文档

### 接口1：用户列表查询

**URL:** `/api/?m=Admin&c=User&a=user`  
**方法:** GET / POST  
**参数:**
- `page` - 页码（默认1）
- `s_keyword` - 关键字搜索（账号、昵称、手机号）
- `s_gid` - 用户组ID筛选
- `s_loginip` - 登录IP筛选
- `status` - 状态筛选（0=全部，1=禁用，2=正常）
- `moneyFrom` - 金额范围（最小值）
- `moneyTo` - 金额范围（最大值）

**返回示例:**
```json
{
  "code": 1,
  "msg": "ok",
  "data": {
    "list": [
      {
        "id": 100001,
        "account": "testuser",
        "nickname": "测试用户",
        "balance": 1000.00,
        "fz_balance": 500.00,
        "status": 2
      }
    ],
    "count": 1,
    "limit": 15,
    "balance": 1000.00,
    "fz_balance": 500.00
  }
}
```

### 接口2：用户更新/新增

**URL:** `/api/?m=Admin&c=User&a=user_update`  
**方法:** POST  
**参数:**
- `id` - 用户ID（0表示新增，>0表示更新）
- `nickname` - 昵称（必填）
- `cbank` - 银行卡号
- `phone` - 手机号
- `password` - 密码（新增时必填）
- `gid` - 用户组ID
- `status` - 状态
- `account` - 账号（新增时必填）

**返回示例（新增）:**
```json
{
  "code": 1,
  "msg": "操作成功",
  "data": {
    "id": 234567,
    "account": "newuser"
  }
}
```

**返回示例（更新）:**
```json
{
  "code": 1,
  "msg": "操作成功",
  "data": {
    "id": 100001,
    "account": "testuser"
  }
}
```

### 接口3：用户删除

**URL:** `/api/?m=Admin&c=User&a=user_delete`  
**方法:** POST  
**参数:**
- `id` - 用户ID（必填）

**返回示例:**
```json
{
  "code": 1,
  "msg": "操作成功",
  "data": null
}
```

### 接口4：用户充值/扣款

**URL:** `/api/?m=Admin&c=User&a=user_pay`  
**方法:** POST  
**参数:**
- `id` - 用户ID（必填）
- `money` - 金额（正数=充值，负数=扣款）
- `ptype` - 操作类型（1=余额，2=冻结余额）
- `remark` - 备注

**返回示例:**
```json
{
  "code": 1,
  "msg": "操作成功",
  "data": {
    "balance": 1100.00,
    "fz_balance": 500.00
  }
}
```

## 🔒 安全特性

### 1. 密码加密

- **算法：** SHA1(MD5(原始密码) + SYS_KEY + "_kwioxklalis")
- **一致性：** 与PHP完全一致
- **密钥：** 使用常量SYS_KEY，与PHP系统共享

### 2. 敏感信息过滤

- 查询用户列表时自动移除password和password2字段
- 防止敏感信息泄露

### 3. 超级管理员保护

- ID=1的超级管理员不能被删除
- 防止误操作导致系统无法管理

### 4. 参数校验

- 所有接口进行参数完整性校验
- 返回明确的错误提示
- 防止SQL注入（使用参数化查询）

### 5. 事务保证

- 充值/扣款操作使用事务
- 失败自动回滚，保证数据一致性
- 使用行锁防止并发问题
