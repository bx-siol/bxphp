# BX系统 .NET 重构架构设计文档

## 📋 项目概述

将 PHP 单体应用重构为基于 .NET 8.0 的分布式微服务架构,采用 DDD(领域驱动设计)分层架构,支持 PostgreSQL 分库分表,实现高并发、高可用的企业级应用。

### 核心目标
- ✅ **现代化架构**: DDD分层架构、依赖注入、CQRS模式
- ✅ **高性能**: 异步编程、连接池、Redis缓存
- ✅ **高可用**: 分库分表、读写分离、服务熔断
- ✅ **分布式**: 分布式锁、分布式事务、消息队列
- ✅ **可扩展**: 微服务架构、横向扩展

## 🎯 核心设计原则

### 1. DDD分层架构

#### 领域层 (Domain Layer)
- **职责**: 核心业务逻辑、业务规则
- **特点**: 不依赖任何外部框架
- **内容**: 实体、值对象、领域服务、领域事件

#### 应用层 (Application Layer)
- **职责**: 用例编排、事务管理
- **特点**: 协调领域对象完成业务用例
- **内容**: 应用服务、DTO、命令/查询

#### 基础设施层 (Infrastructure Layer)
- **职责**: 技术实现细节
- **特点**: 数据持久化、外部服务调用
- **内容**: 仓储实现、缓存、消息队列

#### 表现层 (Presentation Layer)
- **职责**: 用户交互、API暴露
- **特点**: 轻量级,只做参数绑定和结果返回
- **内容**: 控制器、中间件、过滤器

### 2. 依赖注入 (DI)

```csharp
// Program.cs 中注册服务
builder.Services.AddScoped<IUserRepository, UserRepository>();
builder.Services.AddScoped<IUserService, UserService>();
builder.Services.AddSingleton<ICacheService, RedisCacheService>();
builder.Services.AddScoped<IDistributedLock, RedisDistributedLock>();
builder.Services.AddScoped<IUnitOfWork, UnitOfWork>();
```

### 3. 异步编程

所有I/O操作使用异步方法:
```csharp
public async Task<UserDto> GetUserByIdAsync(int userId)
{
    var user = await _userRepository.GetByIdAsync(userId);
    return _mapper.Map<UserDto>(user);
}
```

### 4. 工作单元 (Unit of Work)

保证事务一致性:
```csharp
using (var uow = _unitOfWorkFactory.Create())
{
    await _userRepository.UpdateAsync(user);
    await _walletRepository.UpdateAsync(wallet);
    await uow.CommitAsync();
}
```

## 🔐 分布式锁设计

### Redis分布式锁

```csharp
public interface IDistributedLock
{
    /// <summary>
    /// 获取分布式锁
    /// </summary>
    Task<bool> AcquireLockAsync(string key, TimeSpan expiry);
    
    /// <summary>
    /// 释放分布式锁
    /// </summary>
    Task<bool> ReleaseLockAsync(string key);
    
    /// <summary>
    /// 执行带锁的操作
    /// </summary>
    Task<T> ExecuteWithLockAsync<T>(string key, Func<Task<T>> action, TimeSpan timeout);
}
```

### 使用场景

1. **并发充值扣款**: 防止余额计算错误
```csharp
var lockKey = $"user:balance:{userId}";
await _distributedLock.ExecuteWithLockAsync(lockKey, async () =>
{
    var user = await _userRepository.GetByIdAsync(userId);
    user.Balance += amount;
    await _userRepository.UpdateAsync(user);
}, TimeSpan.FromSeconds(10));
```

2. **抢购活动**: 防止超卖
```csharp
var lockKey = $"product:stock:{productId}";
await _distributedLock.ExecuteWithLockAsync(lockKey, async () =>
{
    var product = await _productRepository.GetByIdAsync(productId);
    if (product.Stock > 0)
    {
        product.Stock--;
        await _productRepository.UpdateAsync(product);
    }
}, TimeSpan.FromSeconds(5));
```

## 💾 缓存策略

### 三级缓存架构

```
请求 → 本地缓存(内存) → Redis缓存 → PostgreSQL数据库
```

### 缓存设计

```csharp
public async Task<UserDto> GetUserAsync(int userId)
{
    // 1. 尝试从本地缓存获取(MemoryCache)
    if (_memoryCache.TryGetValue($"user:{userId}", out UserDto cachedUser))
        return cachedUser;
    
    // 2. 尝试从Redis获取
    var redisUser = await _redisCache.GetAsync<UserDto>($"user:{userId}");
    if (redisUser != null)
    {
        _memoryCache.Set($"user:{userId}", redisUser, TimeSpan.FromMinutes(5));
        return redisUser;
    }
    
    // 3. 从数据库查询
    var user = await _userRepository.GetByIdAsync(userId);
    var userDto = _mapper.Map<UserDto>(user);
    
    // 4. 写入缓存
    await _redisCache.SetAsync($"user:{userId}", userDto, TimeSpan.FromMinutes(30));
    _memoryCache.Set($"user:{userId}", userDto, TimeSpan.FromMinutes(5));
    
    return userDto;
}
```

### 缓存失效策略

| 场景 | 策略 | TTL |
|-----|------|-----|
| 用户信息 | 主动失效 | 30分钟 |
| 配置信息 | 定时刷新 | 10分钟 |
| 热点数据 | 永久缓存 | 无限期 |
| 列表数据 | 被动失效 | 5分钟 |

## 🔄 异步编程最佳实践

### 1. 控制器层

```csharp
[HttpPost("users")]
public async Task<ActionResult<ApiResult>> CreateUser([FromBody] CreateUserRequest request)
{
    var result = await _userService.CreateUserAsync(request);
    return Ok(ApiResult.Success(result));
}
```

### 2. 服务层

```csharp
public async Task<UserDto> CreateUserAsync(CreateUserRequest request)
{
    // 参数验证
    await ValidateUserAsync(request);
    
    // 创建用户
    var user = new SysUser(request.Account, request.Password);
    
    using (var uow = _unitOfWorkFactory.Create())
    {
        await _userRepository.AddAsync(user);
        await uow.CommitAsync();
    }
    
    // 发布领域事件(异步)
    await _eventBus.PublishAsync(new UserRegisteredEvent(user.Id));
    
    return _mapper.Map<UserDto>(user);
}
```

### 3. 仓储层

```csharp
public async Task<SysUser> GetByIdAsync(int userId)
{
    var tableName = ShardingRouter.GetUserTable(userId);
    return await _dbContext.Queryable<SysUser>()
        .AS(tableName)
        .Where(u => u.Id == userId)
        .FirstAsync();
}
```
