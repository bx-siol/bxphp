# PostgreSQL 分库路由实现指南

**注意**: 本文档仅涉及分库路由，分表功能由应用层框架(如ShardingSphere、Citus等)实现。

## 一、路由策略总览

### 1.1 分库路由规则

| 数据库 | 用途 | 路由规则 | 连接配置 |
|--------|------|----------|----------|
| bx_core | 核心业务 | 固定路由 | 主库+2从库 |
| bx_finance | 财务数据 | 固定路由 | 主库+1从库 |
| bx_log | 日志数据 | 按uid哈希 | 主库+1从库 |
| bx_marketing | 营销活动 | 固定路由 | 主库+1从库 |
| bx_trade | 交易订单 | 按时间分区 | 主库+2从库 |

### 1.2 分表实现（应用层框架负责）

**分表由应用层框架实现，推荐方案：**

- **ShardingSphere-JDBC**: 适合Java应用，支持分库分表、读写分离
- **PHP自定义路由**: 在应用层实现表名路由逻辑
- **Citus扩展**: PostgreSQL原生分布式方案(适合超大规模)

**推荐的分表策略**（供参考）：

| 表名 | 推荐分表方式 | 路由键 | 说明 |
|------|----------|--------|------|
| wallet_log | 按uid哈希 | uid | 按用户ID取模分表 |
| pro_reward | 按uid哈希 | uid | 按用户ID取模分表 |
| fin_paylog | 按月 | create_time | 按时间月份分表 |
| fin_cashlog | 按月 | create_time | 按时间月份分表 |
| pro_order | 按月 | create_time | 按时间月份分表 |

### 2.2 分库路由类（分表由应用框架实现）

```php
<?php
// global/lib/DatabaseRouter.class.php

/**
 * 分库路由类
 * 注意: 只负责分库路由，分表由应用层框架实现
 */
class DatabaseRouter
{
    /**
     * 获取数据库连接
     * 
     * @param string $dbName 数据库名称 (bx_core, bx_finance, bx_log, bx_marketing, bx_trade)
     * @param bool $isMaster 是否主库
     * @return \think\db\Connection
     */
    public static function getConnection($dbName, $isMaster = true)
    {
        $config = config("database.{$dbName}");
        
        if ($isMaster) {
            return Db::connect($config['master']);
        }
        
        // 从库随机选择(负载均衡)
        if (isset($config['slaves']) && !empty($config['slaves'])) {
            $slaveConfig = $config['slaves'][array_rand($config['slaves'])];
            return Db::connect($slaveConfig);
        }
        
        // 没有从库则使用主库
        return Db::connect($config['master']);
    }
    
    /**
     * 获取核心库连接
     */
    public static function getCoreDb($isMaster = true)
    {
        return self::getConnection('bx_core', $isMaster);
    }
    
    /**
     * 获取财务库连接
     */
    public static function getFinanceDb($isMaster = true)
    {
        return self::getConnection('bx_finance', $isMaster);
    }
    
    /**
     * 获取日志库连接
     */
    public static function getLogDb($isMaster = true)
    {
        return self::getConnection('bx_log', $isMaster);
    }
    
    /**
     * 获取营销库连接
     */
    public static function getMarketingDb($isMaster = true)
    {
        return self::getConnection('bx_marketing', $isMaster);
    }
    
    /**
     * 获取交易库连接
     */
    public static function getTradeDb($isMaster = true)
    {
        return self::getConnection('bx_trade', $isMaster);
    }
}
```

### 2.3 分表实现建议（应用层框架）

如需实现分表，推荐使用以下方案：

#### 方案1: 使用ShardingSphere (推荐)

```yaml
# sharding-sphere.yaml
dataSources:
  bx_log:
    url: jdbc:postgresql://localhost:5432/bx_log
    username: postgres
    password: admin8

shardingRule:
  tables:
    wallet_log:
      actualDataNodes: bx_log.wallet_log_${0..15}
      tableStrategy:
        standard:
          shardingColumn: uid
          shardingAlgorithmName: wallet_log_mod
  
  shardingAlgorithms:
    wallet_log_mod:
      type: MOD
      props:
        sharding-count: 16
```

#### 方案2: PHP自定义分表路由

```php
<?php
/**
 * 分表路由辅助类（仅供参考）
 */
class TableSharding
{
    /**
     * 按用户ID分表
     */
    public static function getUserTable($baseTable, $uid, $tableCount = 16)
    {
        $suffix = $uid % $tableCount;
        return "{$baseTable}_{$suffix}";
    }
    
    /**
     * 按时间分表
     */
    public static function getTimeBasedTable($baseTable, $time, $format = 'Ym')
    {
        $suffix = date($format, $time);
        return "{$baseTable}_{$suffix}";
    }
}

// 使用示例
$tableName = TableSharding::getUserTable('wallet_log', $uid, 16);
$db->table($tableName)->insert($data);
```

### 2.5 跨库关联查询优化

由于分库后无法直接使用JOIN,需要在应用层进行数据聚合:

```php
<?php
/**
 * 获取用户完整财务信息
 * 
 * @param int $uid 用户ID
 * @return array
 */
function getUserFinanceInfo($uid)
{
    // 1. 从核心库获取用户基本信息
    $coreDb = DatabaseRouter::getCoreDb(false);
    $user = $coreDb->table('sys_user')->where('id', $uid)->find();
    
    // 2. 从财务库获取充值提现统计
    $financeDb = DatabaseRouter::getFinanceDb(false);
    $rechargeSum = $financeDb->table('fin_paylog')
        ->where('uid', $uid)
        ->where('status', 9)
        ->sum('money');
    
    $withdrawSum = $financeDb->table('fin_cashlog')
        ->where('uid', $uid)
        ->where('status', 9)
        ->where('pay_status', 9)
        ->sum('money');
    
    // 3. 从交易库获取订单统计
    $tradeDb = DatabaseRouter::getTradeDb(false);
    $orderSum = $tradeDb->table('pro_order')
        ->where('uid', $uid)
        ->where('status', '<', 99)
        ->sum('money');
    
    // 4. 从日志库获取收益统计
    $logDb = DatabaseRouter::getLogDb(false);
    $rewardSum = $logDb->table('pro_reward')
        ->where('uid', $uid)
        ->sum('money');
    
    // 5. 应用层聚合数据
    return [
        'user' => $user,
        'total_recharge' => $rechargeSum,
        'total_withdraw' => $withdrawSum,
        'total_order' => $orderSum,
        'total_reward' => $rewardSum,
    ];
}
```

### 3.2 缓存策略

```php
<?php
/**
 * 带缓存的用户信息查询
 * 
 * @param int $uid 用户ID
 * @return array
 */
function getUserInfoCached($uid)
{
    $redis = getRedis();
    $cacheKey = "user_info:{$uid}";
    
    // 先从缓存读取
    $userInfo = $redis->get($cacheKey);
    if ($userInfo !== false) {
        return json_decode($userInfo, true);
    }
    
    // 缓存未命中,从数据库读取
    $db = ShardingRouter::getConnection('bx_core', false);
    $userInfo = $db->table('sys_user')->where('id', $uid)->find();
    
    // 写入缓存(1小时)
    if ($userInfo) {
        $redis->setex($cacheKey, 3600, json_encode($userInfo));
    }
    
    return $userInfo;
}
```

### 3.3 批量操作优化

```php
<?php
/**
 * 批量插入钱包流水
 * 
 * @param array $logs 流水数据数组
 * @return int 插入数量
 */
function batchInsertWalletLog($logs)
{
    // 按用户ID分组
    $grouped = [];
    foreach ($logs as $log) {
        $uid = $log['uid'];
        $tableName = ShardingRouter::getWalletLogTable($uid);
        $grouped[$tableName][] = $log;
    }
    
    $db = ShardingRouter::getConnection('bx_log', true);
    $totalInserted = 0;
    
    // 按表批量插入
    foreach ($grouped as $tableName => $tableData) {
        $db->table($tableName)->insertAll($tableData);
        $totalInserted += count($tableData);
    }
    
    return $totalInserted;
}
```

```php
<?php
/**
 * 同库事务示例
 * 注意: PostgreSQL不同数据库间无法使用单一事务
 * 需要使用分布式事务或最终一致性方案

function transferMoney($fromUid, $toUid, $amount)
{
    $logDb = DatabaseRouter::getLogDb(true);

        // 增加转入方余额

            'uid' => $toUid,

            // ...其他字段
        ]);

    }
}
```

### 5.2 PHP监控示例

```php
<?php
/**
 * 数据库性能监控
 */
class DatabaseMonitor
{
    /**
     * 检查慢查询
     */
    public static function checkSlowQueries()
    {
        $dbs = ['bx_core', 'bx_finance', 'bx_log', 'bx_marketing', 'bx_trade'];
        $slowQueries = [];
        
        foreach ($dbs as $dbName) {
            $db = ShardingRouter::getConnection($dbName, false);
            $queries = $db->query("
                SELECT query, calls, mean_exec_time
                FROM pg_stat_statements
                WHERE mean_exec_time > 100
                ORDER BY mean_exec_time DESC
                LIMIT 10
            ");
            
            if (!empty($queries)) {
                $slowQueries[$dbName] = $queries;
            }
        }
        
        return $slowQueries;
    }
    
    /**
     * 检查分区数据倾斜
     */
    public static function checkPartitionSkew()
    {
        $logDb = ShardingRouter::getConnection('bx_log', false);
        
        $stats = [];
        for ($i = 0; $i < 16; $i++) {
            $count = $logDb->table("wallet_log_{$i}")->count();
            $stats["wallet_log_{$i}"] = $count;
        }
        
        $avg = array_sum($stats) / count($stats);
        $skewed = [];
        
        foreach ($stats as $table => $count) {
            $deviation = abs($count - $avg) / $avg * 100;
            if ($deviation > 20) { // 偏差超过20%
                $skewed[$table] = [
                    'count' => $count,
                    'deviation' => round($deviation, 2) . '%'
                ];
            }
        }
        
        return $skewed;
    }
}
```

## 六、迁移建议

### 6.1 数据迁移步骤

1. **准备阶段**
   - 创建PostgreSQL数据库和表结构
   - 配置主从复制
   - 压力测试

2. **迁移阶段**
   - 导出MySQL历史数据
   - 转换数据格式(适配PostgreSQL)
   - 批量导入PostgreSQL
   - 校验数据一致性

3. **切换阶段**
   - 应用层双写(MySQL + PostgreSQL)
   - 灰度切换读流量到PostgreSQL
   - 全量切换
   - 下线MySQL

### 6.2 数据导入脚本示例


### 6.3 兼容性处理

```php
<?php
/**
 * 数据库兼容层
 * 支持MySQL和PostgreSQL切换
 */
class DatabaseCompat
{
    private static $dbType = 'pgsql'; // 或 'mysql'
    
    /**
     * 获取连接
     */
    public static function connect($dbName, $isMaster = true)
    {
        if (self::$dbType === 'pgsql') {
            return ShardingRouter::getConnection($dbName, $isMaster);
        } else {
            // MySQL连接逻辑
            return Db::connect('mysql');
        }
    }
    
    /**
     * 获取钱包流水表名
     */
    public static function getWalletLogTable($uid)
    {
        if (self::$dbType === 'pgsql') {
            return ShardingRouter::getWalletLogTable($uid);
        } else {
            return 'wallet_log'; // MySQL单表
        }
    }
}
```
